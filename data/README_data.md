\# Data access notes



This thesis uses secondary country-year data from three main sources.



\## World Development Indicators (WDI)



Used for:



\- FDI net inflows as a percentage of GDP

\- GDP per capita

\- inflation

\- trade openness



Source: World Bank DataBank, World Development Indicators.



\## Worldwide Governance Indicators (WGI)



Used for:



\- Control of Corruption



Source: World Bank Worldwide Governance Indicators.



\## World Values Survey (WVS)



Used for:



\- WVS Wave 7 corruption-perception item Q112

\- WVS Wave 6 V228A-V228I item set used to construct the perceived-corruption proxy



The WVS-based perceived-corruption proxy is constructed in the notebook and documented in the thesis appendix. Because WVS access conditions may apply, raw WVS data are not redistributed in this repository. Users should download the data from the official WVS website.



\## Unit of analysis



All datasets are merged at the country-year level using:



\- ISO3 country code

\- year



\## Notes



The repository contains analysis code, figures, and output tables. Raw data should be acquired from the original providers and placed in the local data folder following the paths used in the notebook.
