\# Thesis: Comparing perceived and institutional corruption in predicting FDI inflows



This repository contains the reproducibility materials for the MSc Data Science \& Society thesis:



\*\*Comparing perceived and institutional corruption in predicting foreign direct investment inflows\*\*



The thesis compares an institutional corruption measure, the World Bank Worldwide Governance Indicators (WGI) Control of Corruption indicator, with a public-perception corruption proxy constructed from World Values Survey (WVS) data. The dependent variable is FDI net inflows as a percentage of GDP. The analysis is conducted at the country-year level and evaluates predictive performance using cross-validation, multiple model families, matched-sample comparisons, target preprocessing, and error analysis.
